# שעת נחת · אתר שריון מקום

אתר נחיתה ושריון מקום לשמרטפות לתינוקות בגילאי 3 עד 12 חודשים בחריש. האתר מותקן כאפליקציה (PWA) ועובד בלי שרת.

**איך זה עובד היום:** ההורה בוחר יום ושעות, ממלא פרטים, והבקשה נפתחת בוואטסאפ של אנסטסיה עם הודעה מוכנה. ככה היא מקבלת התראה ואת פרטי הקשר של ההורה. אחרי האישור מוצגים הסכום והמספר לתשלום בביט או בפייבוקס.

## הפעלה ב-GitHub Pages (פעם אחת)

1. בריפו: **Settings → Pages**
2. ב-Source לבחור **Deploy from a branch**, ב-Branch לבחור `main`, ובתיקייה `/ (root)`, ואז **Save**
3. אחרי דקה-שתיים האתר עולה בכתובת:
   `https://neilkplanning-svg.github.io/AnastasyaKindergarten/`

## ימים ושעות: גוגל שיטס (אנסטסיה מעדכנת מהטלפון)

הקובץ **שעת נחת – שעות פעילות** בגוגל דרייב:
- **לשונית "שבועי":** לכל יום בשבוע מסמנים V ב"פתוח" ובוחרים "משעה" ו"עד שעה".
- **לשונית "חריגים":** תאריך מסוים. בלי V ב"פתוח" היום סגור (חופש, מחלה, חג). עם V, היום פתוח בשעות שנבחרו, גם אם הוא בדרך כלל סגור.
- האתר קורא את הקובץ בכל כניסה, אז שינוי מופיע תוך דקות.
- **תנאי חובה:** הקובץ משותף כ"כל מי שיש לו את הקישור – צפייה". אחרת האתר חוזר לברירות המחדל שב-`config.js`.

## הגדרות שמשתנות לעיתים רחוקות: `config.js`

| מה רוצים לשנות | איפה בקובץ |
|---|---|
| מחירים | `prices: { 1: 70, 2: 120 }` |
| קובץ השעות | `scheduleSheetId` |
| ימים ושעות לגיבוי | `openDays`, `hours`, `closedDates` |
| משך מקסימלי | `maxHours` |
| קישור פייבוקס | `payboxLink` (כשמוגדר, מופיע כפתור תשלום) |
| תמונות של הבית | להעלות לתיקייה `images/` ולהוסיף ל-`photos` |

אפשר לערוך ישירות באתר GitHub או באפליקציית GitHub בטלפון: נכנסים לקובץ, לוחצים על העיפרון ואז על Commit. האתר מתעדכן לבד.

## התקנה כאפליקציה

- **אנדרואיד (Chrome):** מופיע באתר כפתור "התקנה", או דרך התפריט ← "הוספה למסך הבית". לחיצה ארוכה על האייקון נותנת קיצור דרך ל"שריון מקום".
- **אייפון (Safari):** כפתור השיתוף ← "הוספה למסך הבית".

## מבנה

```
index.html            העמוד
styles.css            עיצוב (מובייל קודם)
app.js                לוגיקה: ימים, משבצות, וואטסאפ, תשלום, התקנה
config.js             הגדרות העסק
manifest.webmanifest  הגדרות אפליקציה + קיצור דרך לשריון
sw.js                 עבודה בלי רשת
icons/                אייקונים ותמונת שיתוף
images/               תמונות הבית
```
